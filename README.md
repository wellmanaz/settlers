# Settlers

A small, browser-based Catan-style island-building game for 2–4 local players.

## Play

Open `index.html` in a modern browser. Choose the number of players and start a
new game to generate an island. Players take turns rolling two dice, collecting
resources from their settlements and cities, and using those resources to build
roads, settlements, and cities. A 4:1 bank trade is also available. The first
player to reach 10 victory points wins.

The board, resource layout, and number tokens are randomized for each game. On
a roll of 7, players holding more than seven resource cards discard half and
the current player moves the robber before continuing.
